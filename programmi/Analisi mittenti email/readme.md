# Analisi dei mittenti email

Programma Python che analizza un archivio email in formato **mbox** e individua il mittente con il maggior numero di messaggi inviati.

## Funzionalità

- Lettura e analisi di file di testo.
- Estrazione degli indirizzi email dai messaggi.
- Conteggio delle occorrenze tramite dizionari.
- Ricerca del mittente più frequente.

## Tecnologie

- Python 3
- File I/O
- Manipolazione di stringhe
- Dizionari e liste

## Nota

Progetto sviluppato come implementazione personale di un esercizio del corso *Python for Everybody*.
