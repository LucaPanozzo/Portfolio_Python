# Analisi dati JSON da URL

Programma Python che recupera dati in formato **JSON** da una risorsa web e analizza il contenuto del dataset calcolando la somma dei valori associati ai record.

## Funzionalità

- Recupero di dati tramite URL.
- Lettura e decodifica di file JSON.
- Parsing di strutture dati JSON.
- Elaborazione e aggregazione dei dati.

## Tecnologie

- Python 3
- JSON
- Richieste HTTP
- Gestione dati strutturati

## Nota

Progetto sviluppato come implementazione personale di un esercizio del corso *Python for Everybody*.
