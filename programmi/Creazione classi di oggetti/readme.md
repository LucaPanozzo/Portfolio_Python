# Creazione classi di oggetti

Programma Python che mostra i principali concetti della programmazione a oggetti attraverso un semplice modello di gestione dei dipendenti.

## Concetti utilizzati

- Creazione di classi e oggetti.
- Utilizzo del costruttore `__init__`.
- Ereditarietà tra classi.
- Utilizzo di `super()` per richiamare il costruttore della classe padre.
- Aggiunta di attributi e metodi specifici nelle classi figlie.

## Tecnologie

- Python 3
