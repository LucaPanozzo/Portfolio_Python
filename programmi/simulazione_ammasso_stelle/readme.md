# Simulazione di un ammasso stellare

Programma Python che simula la distribuzione spaziale e cinematica di un ammasso stellare utilizzando un modello teorico di densità. Il codice genera stelle con distribuzioni casuali di posizione e velocità, analizzandone le proprietà attraverso grafici statistici.

## Funzionalità

- Generazione casuale della posizione delle stelle nell'ammasso.
- Calcolo della distribuzione radiale della massa.
- Simulazione della distribuzione delle velocità stellari.
- Visualizzazione della distribuzione spaziale e delle proprietà dinamiche dell'ammasso.

## Tecnologie

- Python 3
- NumPy
- Matplotlib
- Metodi Monte Carlo
- Simulazioni numeriche

## Contesto

Progetto sviluppato nell'ambito del corso universitario di laurea magistrale in "Astrophysics and Cosmology", con applicazione di metodi computazionali allo studio di sistemi astrofisici.

## Modello utilizzato

La simulazione utilizza un modello sferico di distribuzione stellare con parametri caratteristici dell'ammasso, generando una popolazione di stelle tramite campionamento casuale delle variabili dinamiche
