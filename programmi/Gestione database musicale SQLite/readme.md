# Gestione database musicale SQLite

Programma Python che importa dati musicali da un file CSV e crea un database relazionale SQLite contenente informazioni su artisti, album e brani.

## Funzionalità

- Creazione e gestione di un database SQLite.
- Importazione di dati da file CSV.
- Organizzazione delle informazioni in tabelle correlate.
- Inserimento e recupero di dati tramite query SQL.

## Tecnologie

- Python 3
- SQL
- Gestione database
- Lettura di file CSV

## Nota

Progetto sviluppato come implementazione personale di un esercizio del corso *Python for Everybody*.
